# EngineDJExtractor
I wrote this to extract media files from EngineDJ OS devices easily and automatically due to an accident I had with my music library. Luckily, with this program and my Denon DJ Prime 4, my life was saved!


Usage:

Download, and run the program with your Engine DJ device connected in "Computer Mode" with the USB cable.

In my case, the "Source" location was: H:\Engine Library\Music

Yours will be similar but maybe with a different letter at the beginning.


The process is to navigate to the source folder on the Engine DJ device as mentioned above, then choose an output directory on your computer for all the files to go into.

This program copies the files, so no worries about deleting or ruining anything on your Engine OS device.
